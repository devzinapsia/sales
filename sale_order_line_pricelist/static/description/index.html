Sale order line price list

A different price list per sale order line

This module adds a "Price list" field to each sale order line, independent of the order's own price list. A new line takes the order's price list by default, but the user can pick a different, active price list on that specific line only - the line's unit price is recomputed right away, converted to the order's currency if needed.

This makes it possible to add the same product twice on the same order with two different prices, each coming from a different price list.
