Listas de precios en pedidos de venta

Este instructivo explica cómo trabajar con listas de precios en Odoo Ventas, incluyendo la posibilidad de usar una lista de precios distinta en cada línea del pedido de venta.

¿Qué es una lista de precios?

Una lista de precios es un conjunto de reglas que define a qué precio se vende cada producto: por ejemplo, una lista "Mayorista", otra "Minorista" o una en dólares. Cada pedido de venta tiene una lista de precios en su encabezado, y con este módulo cada línea puede además tomar su precio de otra lista.

Contenido

  1. Cómo se cargan las listas de precios: activar la función, crear una lista y cargar sus reglas.
  2. Cómo se actualizan los precios: modificar las reglas y recalcular los precios de un pedido.
  3. Cómo se usa en el pedido de venta: elegir la lista de precios de cada línea.
💡

En el pedido hay dos campos distintos con el mismo nombre "Lista de precios": el del encabezado (vale para todo el pedido) y la columna de cada línea (vale solo para esa línea). Este instructivo aclara en cada paso a cuál se refiere.
